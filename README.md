# student-attendance-management-system
School Management and Student Attendance System

Project Overview

A web-based school management system developed to support student attendance management and school administration.

Features

- Dashboard and home page
- Admin Office section
- Teacher Office section
- Student attendance management interface
- Project information page

Technologies Used

- HTML
- CSS
- JavaScript (included in the project; functionality depends on the implemented code)

Language

The user interface is primarily in Somali.

Purpose

This project demonstrates practical front-end web development skills and the development of a school management interface.
